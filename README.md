Playwright core package provides framework to automate browser
Playright core = Core automation library

Playwright test runner is a framwork built on top of playwright
Playright test runner = test management+fixtures +assertions+ runners

Page Fixture -> its provided by Playwright which user can use directly in tests for navigation

BrowserContext -> Its an isolated browser session. each context can have its own session,cookies and authentication

Fresh Browser context -> It means if we create a new browser context its fresh isolated session. it wont have any cookies or session or authentication from other context. its like a clean slate.
